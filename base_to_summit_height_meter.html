Read this before climbing

Phone GPS altitude can drift by several meters or more. Trees, cliffs, buildings, weather, and device hardware affect readings. This tool reports raw device altitude and a simple smoothed estimate; it cannot guarantee the mountain’s true height above its base.

How the result works: start altitude = first valid GPS reading; highest altitude = highest smoothed reading so far; height gain = highest altitude − start altitude. The STOP altitude is shown separately. If you stop before reaching the summit or the signal is poor, the result may be misleading.

Location data is processed in this browser and is not uploaded by this page. Keep the phone secure, avoid dangerous routes, and do not rely on GPS alone for navigation.
